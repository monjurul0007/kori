Koriকড়ি

A design refresh proposal from the November 2026 UX audit. কড়ি is the cowrie shell, which Bengal used as money for centuries, so the new mark is a cowrie on flag green. The rest of the refresh is about one question the dashboard should answer at a glance: how much is left to spend this month.

Dashboard on a phone

Today the first card is the budget and the month's total spend appears only inside it. The proposal leads with what's left, keeps spent, income and net one glance below, and turns the over-budget warning into a single line.

Adding an expense

  • Save is always visible.A sticky footer button that names the result ("Save ৳250 expense"), then a toast "Saved ৳250 to Food" with Undo.
  • Category grid with icons.44px tiles the thumb can hit, using the icons people already pick in Settings. "More" opens the full list.
  • Optional fields as chips.Date, payment method and merchant stay one tap away. Tags, note and split sit behind one disclosure.
  • Drafts survive.Closing a half-filled sheet asks "Discard this expense?" instead of clearing it silently.

Palette

Flag green stays the brand colour, with porcelain neutrals that lean green and one warm cowrie ivory used only on the mark and the budget track. Contrast figures are against white (light theme); every text pair passes WCAG AA.

Type

Both families are drawn for Bangla and Latin together, so a Bangla interface or Bangla numerals later needs no new fonts. Numbers use tabular figures so amounts line up in lists.
