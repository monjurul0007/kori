# Changelog

All notable changes to Kori, by release. Releases are tagged by the owner at the end of each
milestone. Entries link to the pull requests; see [ROADMAP.md](ROADMAP.md) for what comes next.

## v0.2.0: Plan it (Milestone 2)

Monthly budgets, a dashboard, a split editor and recurring transactions, plus an installable PWA
that works offline and a Playwright smoke test in CI.

### Features

- **Budgets.** Monthly limits per category or overall, carried forward until changed
  ([#23](https://github.com/monjurul0007/kori/pull/23) API,
  [#29](https://github.com/monjurul0007/kori/pull/29) page).
- **Reports and dashboard.** Spending, budget status and a six-month trend from the API
  ([#27](https://github.com/monjurul0007/kori/pull/27)), shown on a dashboard with budget warnings
  and a breakdown by category ([#28](https://github.com/monjurul0007/kori/pull/28)).
- **Split editor.** One transaction across several categories, in the add and edit form
  ([#24](https://github.com/monjurul0007/kori/pull/24)).
- **Settings.** Categories and payment methods
  ([#25](https://github.com/monjurul0007/kori/pull/25)) and tags
  ([#30](https://github.com/monjurul0007/kori/pull/30)).
- **Recurring transactions.** Rules model and API
  ([#31](https://github.com/monjurul0007/kori/pull/31)), a rules page
  ([#40](https://github.com/monjurul0007/kori/pull/40)) and the job that creates due transactions
  ([#43](https://github.com/monjurul0007/kori/pull/43)).
- **CSV export** of transactions ([#32](https://github.com/monjurul0007/kori/pull/32)).
- **PWA polish.** Install prompt, update toast and an offline shell
  ([#34](https://github.com/monjurul0007/kori/pull/34)).

### Fixes

- A tag typed but not confirmed with Enter is now saved
  ([#39](https://github.com/monjurul0007/kori/pull/39)).
- The transaction form warns before discarding what you typed, and Save stays visible on laptop
  screens ([#42](https://github.com/monjurul0007/kori/pull/42)).

### Testing and docs

- Playwright smoke test against the Compose stack
  ([#35](https://github.com/monjurul0007/kori/pull/35)).
- Spikes: PWA capabilities on iOS and Android ([#33](https://github.com/monjurul0007/kori/pull/33))
  and background jobs on scale-to-zero hosting
  ([#38](https://github.com/monjurul0007/kori/pull/38), ADR-0006).
- README screenshots and GIF, regenerated by `pnpm screenshots`; the data model in
  `docs/architecture.md` now includes budgets and recurring rules.

## Milestone 1: Log it, live (before releases were tagged)

Login, fast expense and income entry on a phone (installable PWA), split transactions and tags, a
monthly list with totals and search, a deterministic demo seed, CI/CD to free-tier hosting, and the
`kori-ai` scaffold. See the merged PRs [#3](https://github.com/monjurul0007/kori/pull/3) to
[#20](https://github.com/monjurul0007/kori/pull/20).
